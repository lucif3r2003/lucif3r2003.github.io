# lucif3r_potfolio

Portfolio site scaffolded with Vite + React. Dark modern theme.

Quick start:

```bash
cd lucif3r_potfolio
npm install
npm run dev
```

How to use:
- Edit `src/data/resume.json` and paste your CV details there.
- Add project entries in `src/components/Projects.jsx` or create a data file.
- Replace placeholder text and images in `src/components/*` with your content.
